# Wayfile brand pack

![Wayfile — Agents, routed.](wayfile-hero.png)

A folded file becomes a branching W. The identity connects the two halves of Wayfile: files you can review and routes that choose where work goes.

## Identity

| Token | Value | Role |
| --- | --- | --- |
| Signal yellow | `#FFD600` | Primary brand field and emphasis |
| Near black | `#111111` | Type, route lines, and contrasting fields |
| Wordmark | `wayfile` | Lowercase |
| Tagline | `Agents, routed.` | Product signature |

Use yellow on black or black on yellow. Generated raster pixels include edge antialiasing and slight tonal variation; the hex values above are the intended colors for authored UI and type.

Keep clear space around the mark of at least one routing-node diameter. Preserve the file corner and the W-shaped branch. Use a bold geometric sans serif for headings and a familiar monospace for code. Keep layouts direct, generous, and precise; diagram-like routing paths can provide structure without crowding the message.

## Product language

Lead with fast deterministic paths, reviewable policy, and focused model calls. Describe current capabilities plainly. Benchmark claims must identify the dataset, model, framework versions, and whether the comparison uses an actual runtime or a simulation. Rule learning and automatic promotion remain roadmap features.
